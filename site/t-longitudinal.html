Глава 3. Продольная остойчивость и дифферент

3.1. Продольный метацентр

Вся механика главы 2 переносится на наклонения в диаметральной плоскости: ватерлиния поворачивается вокруг поперечной оси через центр тяжести своей площади F (точка x_f!), радиус —

R = I_yf / V,

где I_yf — момент инерции площади ВЛ относительно поперечной оси через x_f. Так как длина в квадрате велика, R — порядка длины судна (у нашего корпуса ≈ 150 м при L = 100 м): продольная остойчивость огромна, судно не «клюёт», а плавно меняет дифферент. Продольная метацентрическая высота H = z_c + R − z_g ≈ R.

3.2. Момент, дифферентующий на 1 см

Дифферент d = T_н − T_к связан с углом: d = L·tgψ ≈ L·ψ. Из метацентрической формулы M_диф = D·H·ψ получаем момент, изменяющий дифферент на 1 см:

m_д = D·H/(100·L) [т·м/см].

Вторая рабочая константа судна рядом с q (т/см из гл. 1) — обе печатают в грузовой шкале.

3.3. Приём груза: осадки носом и кормой — по шагам

Груз m принят в точке с абсциссой x (от миделя):

  1. среднее приращение осадки δT = m/(ρS) — судно садится «параллельно» так, будто груз принят в точке F (центре тяжести ВЛ, x_f);
  2. момент относительно F: M = m·(x − x_f) — дифферентует;
  3. изменение дифферента δd = M/m_д (см);
  4. раскладка по маркам (нос/корма отстоят от F на L/2 ∓ x_f): δT_н = δT + δd·(L/2 − x_f)/L; δT_к = δT − δd·(L/2 + x_f)/L.

Заметьте роль x_f: параллельная посадка происходит вокруг центра ватерлинии, а не миделя — и разность x_c − x_f из решателя определяет, куда судно дифферентуется при простой перегрузке.

3.4. Диаграмма посадок

Для быстрых решений строят диаграмму: по осям T_н и T_к, семейства прямых D = const и x_g = const. Любая пара (D, x_g) из таблицы нагрузки даёт точку — посадка считывается без вычислений. В курсовой её заменяют кривые элементов + формулы этой главы.
