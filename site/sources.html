Источники и литература

Все нормативные числа сайта (критерии ДСО, критерий погоды, формулы SGISC) выверены по первоисточникам — официальным текстам ИМО и Российского морского регистра судоходства. Даты обращения: 12.08.2026.

Нормативные документы

  1. International Code on Intact Stability, 2008 (2008 IS Code) : resolution MSC.267(85). — IMO, 2008. — официальный PDF, HTML-версия — критерии п. 2.2 (площади 0,055/0,09/0,03 м·рад; плечо 0,2 м при 30°; максимум ≥ 25°; GM₀ ≥ 0,15 м) и критерий погоды п. 2.3.
  2. Правила классификации и постройки морских судов. Ч. IV «Остойчивость». — СПб. : Российский морской регистр судоходства, 2018. — НД № 2-020101-104. — PDF на rs-class.org — требования РС строже ИМО: lmax ≥ 0,25 м (L ≤ 80 м) при θmax ≥ 30°; давление ветра по районам плавания 504/353/252 Па.
  3. Interim Guidelines on the Second Generation Intact Stability Criteria : MSC.1/Circ.1627. — IMO, 10.12.2020. — PDF, HTML — пять отказных режимов; формулы уровня 1, реализованные на странице «Современные критерии».

  4. Кочнев Ю. А. Статика корабля : учеб.-метод. пособие к курсовому проекту. — 2017. — запись НЭБ

Формулы, использованные в расчётах

  1. Период бортовой качки: T = 2CB/√h, C = 0,373 + 0,023·B/d − 0,043·Lwl/100 — Кодекс ОСНС п. 2.3.4 и РС ч. IV п. 2.1.5.1 (обе редакции совпадают); практическая «капитанская» форма T ≈ c·B/√h, c ≈ 0,73–0,88.
  2. Метацентрический радиус r = Ix/V; продольный R = Iyf/V — классика (Семёнов-Тян-Шанский, гл. о начальной остойчивости).
  3. Поправка на свободные поверхности δh = Σρжix/Δ — Кодекс ОСНС ч. B гл. 3.1; РС ч. IV п. 1.4.7 (учёт при заполнении < 98 %).

Материалы курса

Сайт построен по структуре курсовых работ курса «Теория корабля» СПбГМТУ (статика: кривые элементов + диаграммы остойчивости; динамика: качка) и проверен по перечисленным первоисточникам. Соседние сайты кластера: начертательная геометрия (теоретический чертёж) и строймех корабля.
